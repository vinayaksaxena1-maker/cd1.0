## Critical Boundaries
- **No Puppeteer**: Web automation is strictly prohibited for mobile testing. Use `google-artemis`.
- **YAGNI & Modular**: Minimal code, zero dependency bloat, 300-line modular component rule.
- **Git Safety**: Always checkpoint commit before major architectural shifts.
